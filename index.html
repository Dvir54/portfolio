Job Search Agent

An AI agent that finds junior roles in Israel and tailors my CV to each one.

  1. Collect LinkedIn postings
  2. Filter and deduplicate
  3. Claude scores the fit
  4. Tailor the CV in Canva
  5. Send the daily email
fit88

Every morning it collects new LinkedIn postings, deduplicates them, has Claude score each one against my CV with written reasoning, generates a tailored CV for strong matches, and emails me the results. It never applies on its own; I decide.

View the code
  • LLM for judgment, deterministic code for enforcement: filtering, dedup and persistence stay in tested Python.
  • Guards run as hooks on the agent's tool calls and reject a CV that claims a skill the base CV doesn't support.
  • Runs as a scheduled task and sends an email every day, even when a run fails.
  • Python
  • Claude Agent SDK
  • MCP
  • Canva
  • PostgreSQL
  • Docker

New users take a short onboarding quiz about the coins they follow, their investor type and the content they want. The dashboard then combines live prices, market news and an AI-written analysis tailored to those answers, and likes and dislikes on each item shape what comes next.
